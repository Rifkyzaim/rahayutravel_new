GOOD TRAVEL 2.0 — iOS LIQUID GLASS DEMO

JALANKAN:
1. Extract file ZIP.
2. Klik dua kali index.html untuk membuka di Chrome.
3. Lebih nyaman untuk development: buka folder ini di VS Code, install extension Live Server, lalu klik kanan index.html > Open with Live Server.

ADMIN DEMO:
- Klik tombol Admin.
- PIN demo: 1234.
- Fitur: daftar booking lokal, ubah status, hapus booking, export CSV, tambah/hapus jam demo.

WAJIB DISESUAIKAN:
- Edit ADMIN_WA di script.js menjadi nomor WhatsApp admin dengan format 62... tanpa tanda +.
- Harga Rp90.000 dan jam keberangkatan hanyalah nilai contoh; pastikan sesuai operasional sebenarnya.

BATASAN PENTING:
Ini prototipe front-end, belum siap produksi. Data hanya tersimpan di localStorage browser/perangkat yang sama. PIN demo tidak aman, jadwal belum terhubung ke armada nyata, tidak ada pencegahan double-booking lintas pengguna, dan pembayaran belum terintegrasi. Untuk penggunaan bisnis nyata, tambahkan backend/database, autentikasi admin yang aman, validasi kursi di server, kebijakan privasi, dan pengamanan data pelanggan.
